Raycast extension to help validate lego prices and if its worth buying.

## Paths

### 1. Set Number

1. Search for set by the Number
2. Search for the value in lego store in NL and US
3. Search for online retailers in US and NL
4. Calculate the PPP (Price per piece) for each
5. Convert values to BRL using today's currency conversion
6. Display the information in a detail window: Set details, lego prices and PPP in US/EUR/BRL, lowest market price and equivalent PPP in US/EUR/BRL


### 2. Name

1. Search using name for set Number
2. See Path #1.
